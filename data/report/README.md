# Полные отчёты по игровым дням

За каждый **игровой день** (дата начала матчей по московскому времени)
монитор складывает сюда один файл:

- `5.11.txt`, `6.11.txt`, `7.11.txt`, … — имя файла = день.месяц

Внутри файла — **все** игры этого игрового дня и все их проверки от первого
появления в линии до закрытия линии (последней проверки перед началом матча).
Проверки после начала матча не попадают в файл.

Формат: у каждого матча своя шапка (номер, время начала, число проверок
и сдвигов), ниже — строки проверок:

```
1. ВАШИНГТОН УИЗАРДС – АТЛАНТА ХОКС
   начало 05 ноя 03:00 · проверок: 4 · сдвигов форы: 1
    04 ноя 23:57   [+3.5 (1.83) / -3.5 (1.98)]
🔴  05 ноя 02:36   [+1.5 (1.97) / -1.5 (1.83)]
```

- 🔴 — фора изменилась относительно предыдущей проверки
  (движение коэффициентов изменением не считается)
- Если фора не менялась 2 часа и дольше, промежуточные проверки
  «без изменений» схлопываются в строку
  `··· далее N проверок без изменений (последняя …) ···`;
  в шапке матча «проверок: N» всегда показывает полный объём проверок
- Файл игрового дня дополняется после каждой проверки (каждые 30 минут)
  и остаётся в папке навсегда — это архив прошедшего дня

# Архив изменений по игровым дням

В эту папку за каждый **игровой день**, в котором хотя бы у одной игры
сдвинулась фора, монитор складывает пару файлов:

- `ГГГГ-ММ-ДД.txt` — текстовый вариант (строки со сдвигом помечены 🔴)
- `ГГГГ-ММ-ДД.html` — для браузера (строки со сдвигом выделены красным целиком)

Дата в имени файла — день **начала матчей** по московскому времени.

Внутри файла — только игры со сдвигами форы и все их проверки от появления
в линии до начала матча. Движение коэффициентов изменением не считается.

Когда матч завершился (примерно через 2,5–3 часа после начала), в конце его
блока появляется строка с итоговым счётом, например:

```
Итоговый счёт: 105:120
```

Счёт приведён в порядке команд из названия матча (первое число — очки первой
команды). Если в матче был овертайм, строка выглядит так:

```
Итоговый счёт: 116:117 (овертайм)
```

Счёты берутся из официальных результатов NBA (публичный API ESPN) и
сохраняются в `data/results.json`, поэтому строка не исчезает при
пересборке файлов.

Пока сдвигов форы не было — файлов в папке нет. Как только мониторинг поймает
первый сдвиг, файл игрового дня появится автоматически после ближайшей
проверки (каждые 30 минут).
